# Project 1: Build Your Personal Website with AI!
In this project, you will leverage AI and your knowledge of HTML and CSS to build a simple, single-page personal website that will showcase your projects.

You will use AI to help you brainstorm design ideas, apply web development best practices, and troubleshoot issues, bringing your vision to life on screen! 

## Website plan

This portfolio uses a simple, single-page structure made with HTML and CSS only:

- Hero section with an introduction and link to the projects
- About section with a short biography and personal photo
- Skills section for HTML, CSS, responsive design, and JavaScript
- Projects section for course work and future projects
- Contact section with an email link

The visual style is inspired by clean editorial portfolio websites such as [Brittany Chiang's portfolio](https://brittanychiang.com/) and [Adham Dannaway's portfolio](https://www.adhamdannaway.com/). This site uses their clear navigation, strong project focus, and readable spacing as inspiration, but keeps the layout simpler and uses no JavaScript so it is easy to edit while learning. It also has its own gold-and-black color palette.
